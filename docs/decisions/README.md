# Architecture decision records

One file per decision that is hard to reverse or crosses modules: a new
convention, a floor raised across modules, a provider-major policy, a
breaking interface. Small, reversible decisions live in their pull request.

- Copy [0000-template.md](0000-template.md) to `NNNN-short-title.md`, next
  number, and propose it in a pull request.
- Status moves `proposed` → `accepted`, or later `superseded by NNNN`.
  Records are never deleted.
- A module-specific record may live in `modules/<name>/docs/decisions/`
  instead, numbered on its own.
